What is the CIA Triad?	<b>Confidentiality</b> — only authorized users can access data<br><b>Integrity</b> — data is not altered without authorization<br><b>Availability</b> — systems are accessible when needed<br><br><i>Every security decision maps back to one or more of these.</i>	concepts
What is the difference between Authentication and Authorization?	<b>Authentication</b> — proving WHO you are (username + password, MFA)<br><b>Authorization</b> — determining WHAT you are allowed to do (permissions, roles)<br><br><i>You can be authenticated but not authorized. Example: logged in but no admin rights.</i>	concepts
What are the 7 layers of the OSI model (top to bottom)?	7 — Application (HTTP, DNS, FTP)<br>6 — Presentation (encryption, encoding)<br>5 — Session (sessions, authentication)<br>4 — Transport (TCP, UDP, ports)<br>3 — Network (IP, routing)<br>2 — Data Link (MAC addresses, switches)<br>1 — Physical (cables, signals)<br><br><i>Mnemonic (top→bottom): All People Seem To Need Data Processing</i>	networking
What is the TCP 3-way handshake?	The process that establishes a TCP connection:<br>1. <b>SYN</b> — client sends synchronization request<br>2. <b>SYN-ACK</b> — server acknowledges and syncs back<br>3. <b>ACK</b> — client acknowledges<br><br>Connection is now established. Visible in Wireshark.	networking
What is the difference between IDS and IPS?	<b>IDS</b> (Intrusion Detection System) — monitors and <u>alerts</u> on suspicious traffic. Passive — does not block.<br><b>IPS</b> (Intrusion Prevention System) — monitors and <u>blocks</u> suspicious traffic. Active — sits inline.<br><br><i>Think: IDS = smoke alarm. IPS = sprinkler system.</i>	concepts blue-team
What is SQL Injection (SQLi)?	A web vulnerability where an attacker inserts SQL code into an input field to manipulate the database query.<br><br><b>Example payload:</b> <code>' OR 1=1--</code><br><b>Impact:</b> data exfiltration, authentication bypass, data deletion<br><b>Fix:</b> use parameterized queries / prepared statements — never concatenate user input into SQL	appsec
What is Cross-Site Scripting (XSS)?	A vulnerability where an attacker injects malicious JavaScript into a web page viewed by other users.<br><br><b>Types:</b><br>• Reflected — script in URL, executed immediately<br>• Stored — script saved in DB, executed for every visitor<br>• DOM-based — script manipulates the DOM client-side<br><br><b>Impact:</b> session hijacking, keylogging, defacement<br><b>Fix:</b> output encoding, Content Security Policy (CSP)	appsec
What does MITRE ATT&CK stand for, and what is it?	<b>Adversarial Tactics, Techniques & Common Knowledge</b><br><br>A globally accessible knowledge base of real-world adversary behavior.<br>• <b>Tactics</b> = the WHY (e.g. Initial Access, Persistence, Exfiltration)<br>• <b>Techniques</b> = the HOW (e.g. T1566 Phishing, T1078 Valid Accounts)<br><br>Used to map attacks in incident reports and build detection rules.	mitre concepts
What are the key ports you must know by heart?	<b>22</b> — SSH<br><b>23</b> — Telnet (insecure, avoid)<br><b>25</b> — SMTP (email sending)<br><b>53</b> — DNS<br><b>80</b> — HTTP<br><b>443</b> — HTTPS<br><b>445</b> — SMB (Windows file sharing)<br><b>3306</b> — MySQL<br><b>3389</b> — RDP (Windows Remote Desktop)<br><b>8080</b> — HTTP alternate / web proxies	networking
What is SSRF (Server-Side Request Forgery)?	A vulnerability where an attacker tricks the server into making HTTP requests to an unintended destination — often internal services.<br><br><b>Example:</b> changing a URL parameter from <code>https://external.com</code> to <code>http://169.254.169.254/</code> (AWS metadata endpoint)<br><b>Impact:</b> internal network scanning, cloud credential theft, bypassing firewalls<br><b>Fix:</b> allowlist of permitted URLs, disable internal metadata endpoints	appsec
What is the Linux kernel?	The <b>kernel</b> is the core of the operating system — the middleman between hardware and software.<br><br>It manages: CPU, memory, storage, and hardware devices.<br><br><i>Linux = the kernel. Kali, Ubuntu, Parrot = distributions built on top of the Linux kernel.</i>	linux concepts
What is a Linux distribution (distro)?	A packaged operating system built on top of the Linux kernel.<br><br>Includes: the kernel + GNU tools + desktop environment + pre-installed software.<br><br><b>Examples:</b><br>• <b>Kali Linux</b> — security/pentesting tools pre-installed<br>• <b>Parrot OS</b> — lighter, security + privacy focused<br>• <b>Ubuntu</b> — general purpose, beginner friendly	linux concepts
What does the <code>pwd</code> command do?	<b>Print Working Directory</b> — shows your current location in the file system.<br><br><b>Example output:</b> <code>/home/kali/Desktop</code><br><br>The path always starts from <code>/</code> (root — the top of the entire Linux file system).	linux
What does the <code>ls</code> command do?	<b>List</b> — shows the files and folders in your current directory.<br><br><b>Useful flags:</b><br>• <code>ls -l</code> — long format (permissions, owner, size, date)<br>• <code>ls -a</code> — show hidden files (files starting with .)<br>• <code>ls -la</code> — both combined	linux
What does the <code>cd</code> command do?	<b>Change Directory</b> — navigate to a different folder.<br><br><b>Examples:</b><br>• <code>cd Desktop</code> — go into Desktop folder<br>• <code>cd ..</code> — go up one level<br>• <code>cd ~</code> — go to home directory (<code>/home/kali</code>)<br>• <code>cd /</code> — go to root of the file system	linux
What is the Linux file system root (<code>/</code>)?	The <b>root</b> of the Linux file system — the very top of the directory tree. Everything lives under <code>/</code>.<br><br><b>Key directories:</b><br>• <code>/home</code> — user home folders<br>• <code>/etc</code> — system configuration files<br>• <code>/var</code> — logs and variable data<br>• <code>/tmp</code> — temporary files<br>• <code>/bin</code> — essential system binaries	linux
What is the difference between the Linux terminal and a GUI?	<b>GUI</b> (Graphical User Interface) — point and click. Easier to learn but slower for power users.<br><b>Terminal</b> — text-based command line. Faster, more powerful, required for security work.<br><br>Almost all hacking and defense tools are terminal-based. In real security work, you rarely use a GUI.	linux concepts
Why is Linux the industry standard for cybersecurity?	Three reasons:<br>1. <b>Servers run Linux</b> — nearly every web/cloud server on the internet uses it<br>2. <b>Security tools are built for Linux</b> — Nmap, Wireshark, Metasploit, Burp Suite all run natively<br>3. <b>Open source</b> — code is public, auditable, and free to modify<br><br>Windows support for security tools is often an afterthought.	linux concepts
What does <code>cd ..</code> do?	Moves up one level in the directory tree.<br><br><b>Example:</b> if you are in <code>/home/kali/Desktop</code>, running <code>cd ..</code> takes you to <code>/home/kali</code><br><br><i>Note: there must be a space between <code>cd</code> and <code>..</code></i>	linux
What does <code>whoami</code> do?	Prints the current logged-in username.<br><br><b>Example output:</b> <code>kali</code><br><br>Useful in security to confirm which user context you are operating in — especially important when checking for root/admin privileges.	linux
What does <code>uname -a</code> do?	Prints full system information about the Linux kernel and machine.<br><br><b>Example output:</b> <code>Linux kali 6.19.14 #1 SMP x86_64 GNU/Linux</code><br><br>Shows: hostname · kernel version · architecture (x86_64 = 64-bit) · OS type	linux
How do you navigate to a nested folder from the root directory <code>/</code>?	Use the full <b>absolute path</b> — write the entire path from <code>/</code> to your destination in one command.<br><br><b>Example:</b> to get to a folder called <code>projects</code> inside <code>Documents</code> inside the kali home folder:<br><code>cd /home/kali/Documents/projects</code><br><br>Each <code>/</code> separates one folder level. You can go as deep as you need in a single command — no need to <code>cd</code> one step at a time.	linux
What does the <code>cat</code> command do?	<b>Concatenate</b> — prints the contents of a file to the screen.<br><br><b>Example:</b> <code>cat readme</code> — prints the contents of the file called "readme"<br><br><b>Common uses:</b><br>• Read a file: <code>cat filename</code><br>• Read multiple files: <code>cat file1 file2</code><br>• Combine files: <code>cat file1 file2 > combined</code><br><br><i>If you run <code>cat</code> with no filename it waits for keyboard input — press Ctrl+C to cancel.</i>	linux
What is SSH and how do you use it?	<b>SSH (Secure Shell)</b> — a protocol for securely connecting to a remote Linux machine over the network. All traffic is encrypted.<br><br><b>Basic syntax:</b><br><code>ssh username@hostname -p port</code><br><br><b>Example (Bandit):</b><br><code>ssh bandit0@bandit.labs.overthewire.org -p 2220</code><br><br>Default port is 22. Use <code>-p</code> to specify a different port.<br>When connecting for the first time, type <code>yes</code> to accept the host fingerprint.	linux tools
What happens when you run <code>cat</code> with no filename?	It waits for keyboard input — anything you type gets echoed back when you press Enter.<br><br>This is not an error, but it means you forgot to give it a filename.<br><br>Press <b>Ctrl+C</b> to cancel and get your prompt back.	linux
What does <b>Ctrl+C</b> do in the Linux terminal?	Cancels the currently running command and returns you to the prompt.<br><br>Use it when:<br>• A command is stuck or running too long<br>• You ran <code>cat</code> or another command without arguments and it's waiting for input<br>• Any process you want to stop immediately	linux
How do you read a file whose name starts with a dash (<code>-</code>)?	Use <code>./</code> before the filename to treat it as a path, not a flag.<br><br><b>Example:</b> <code>cat ./-</code><br><br>Without <code>./</code>, the shell thinks <code>-</code> is a command flag and throws an error.	linux
What does <code>./</code> mean in Linux?	<b>Current directory</b> — the dot refers to where you are right now.<br><br><code>./filename</code> means "the file called filename in the current directory".<br><br>Used when: filenames start with <code>-</code>, or when running a script in the current folder: <code>./script.sh</code>	linux
How do you read a file whose name contains spaces?	Wrap the filename in <b>quotes</b>:<br><code>cat "spaces in this filename"</code><br><br>Without quotes, the shell treats each word as a separate argument and throws an error.	linux
What does <code>--</code> mean in a Linux command?	It signals the <b>end of flags</b> — everything after <code>--</code> is treated as a filename or argument, not a flag.<br><br><b>Example:</b> <code>cat -- "--filename-with-dashes"</code><br><br>Useful when a filename starts with <code>-</code> and even <code>./</code> doesn't work.	linux
How do you show hidden files with <code>ls</code>?	Use the <code>-a</code> flag (a = all):<br><code>ls -a</code><br><br>Hidden files in Linux start with a dot (<code>.</code>) and are invisible to plain <code>ls</code>.<br><br>You will always see <code>.</code> (current directory) and <code>..</code> (parent directory) in the output.	linux
What do <code>.</code> and <code>..</code> mean in a directory listing?	<code>.</code> = the <b>current directory</b> itself<br><code>..</code> = the <b>parent directory</b> (one level up)<br><br>That's why <code>cd ..</code> goes up one level — you are navigating into <code>..</code>.<br><br>These appear in every <code>ls -a</code> output.	linux
What does the <code>file</code> command do?	Tells you what <b>type of data</b> a file contains — regardless of its name or extension.<br><br><b>Example:</b> <code>file somefile</code><br><b>Output:</b> <code>somefile: ASCII text</code> or <code>data</code> or <code>ELF 64-bit executable</code><br><br><b>Tip:</b> use <code>file ./*</code> to check all files in a directory at once.	linux
What does <b>ASCII text</b> mean in <code>file</code> command output?	The file contains <b>human-readable text</b> — plain characters you can read with <code>cat</code>.<br><br>Other common outputs:<br>• <code>data</code> — binary, not human-readable<br>• <code>ELF 64-bit executable</code> — a compiled program<br>• <code>OpenPGP Secret Key</code> — encrypted key file	linux
What does <code>ls -la</code> do?	Combines two flags:<br>• <code>-l</code> = long format (shows permissions, owner, size, date)<br>• <code>-a</code> = show all including hidden files<br><br><b>Example output:</b><br><code>-rw-r--r-- 1 kali kali 33 Jul 2 readme</code><br><br>This is the most useful form of <code>ls</code> for security work.	linux
What does <code>grep</code> do?	Searches through a file and prints only the lines that contain a matching word or pattern.<br><br><b>Basic syntax:</b> <code>grep "word" filename</code><br><b>Example:</b> <code>grep "millionth" data.txt</code><br><br>One of the most used commands in Linux security work — used to find passwords, usernames, error messages, and IOCs in log files.	linux
How do you search for a specific word inside a file?	Use <code>grep</code>:<br><code>grep "searchterm" filename</code><br><br><b>Useful flags:</b><br>• <code>-i</code> — case insensitive<br>• <code>-r</code> — search recursively through directories<br>• <code>-n</code> — show line numbers<br>• <code>-v</code> — show lines that do NOT match	linux
How do you use <code>find</code> to search by file owner and group?	Use <code>-user</code> and <code>-group</code> flags:<br><code>find / -user bandit7 -group bandit6 -size 33c</code><br><br>You can combine as many conditions as you need — <code>find</code> applies all of them.	linux
How do you hide "Permission denied" errors in <code>find</code> output?	Add <code>2>/dev/null</code> to the end of the command:<br><code>find / -name "file" 2>/dev/null</code><br><br><code>2></code> redirects error output (stderr). <code>/dev/null</code> is a black hole — anything sent there is discarded.<br><br>This keeps the output clean so you only see actual results.	linux
What are the size units for the <code>find -size</code> flag?	<code>c</code> = bytes<br><code>k</code> = kilobytes<br><code>M</code> = megabytes<br><code>G</code> = gigabytes<br><br><b>Example:</b> <code>find . -size 1033c</code> finds files exactly 1033 bytes in size.	linux
What does <code>echo</code> do? (short for: it has no abbreviation — it just echoes)	Prints text to the screen, or writes text into a file.<br><br><b>Print to screen:</b> <code>echo "Hello World"</code><br><b>Write to file:</b> <code>echo "password123" > passwords</code><br><b>Append to file:</b> <code>echo "tryhackme" >> passwords</code><br><br>Also used in scripts to display output to the user.	linux
What is scripting / bash scripting? What is a script made of, and why is it useful?	A <b>script</b> is a file containing a list of commands that run automatically, one after another.<br><br><b>What it's made of:</b><br>• Regular terminal commands (<code>ls</code>, <code>echo</code>, <code>grep</code>...)<br>• Variables: <code>name="kali"</code><br>• Logic: <code>if</code>, <code>for</code>, <code>while</code><br><br><b>Why useful:</b> automates repetitive tasks — e.g. scan 100 IPs, check 50 log files, rename 1000 files.<br><br><b>Run a script:</b> <code>./script.sh</code><br><b>First line of every bash script:</b> <code>#!/bin/bash</code>	linux

What are the full names (what they stand for) of these commands: <code>pwd</code>, <code>ls</code>, <code>cd</code>, <code>cat</code>, <code>grep</code>, <code>ssh</code>?	<code>pwd</code> — <b>Print Working Directory</b><br><code>ls</code> — <b>List</b><br><code>cd</code> — <b>Change Directory</b><br><code>cat</code> — <b>Concatenate</b><br><code>grep</code> — <b>Global Regular Expression Print</b><br><code>ssh</code> — <b>Secure Shell</b><br><code>chmod</code> — <b>Change Mode</b> (permissions)<br><code>sudo</code> — <b>Superuser Do</b><br><code>rm</code> — <b>Remove</b><br><code>mv</code> — <b>Move</b><br><code>cp</code> — <b>Copy</b>	linux
What are the Linux shell operators and what does each do?	<code>&</code> — run a command in the <b>background</b> so you can keep using the terminal<br><br><code>&&</code> — run two commands in sequence; the second only runs <b>if the first succeeds</b><br>Example: <code>cd /tmp && ls</code><br><br><code>></code> — <b>redirect output</b> to a file, <u>overwriting</u> it<br>Example: <code>echo "hello" > file.txt</code><br><br><code>>></code> — <b>append output</b> to a file, without overwriting<br>Example: <code>echo "world" >> file.txt</code>	linux
What is the difference between <code>></code> and <code>>></code>?	Both redirect output into a file.<br><br><code>></code> — <b>overwrites</b> the file. If the file already had content, it's gone.<br><code>>></code> — <b>appends</b> to the file. Existing content is kept, new content is added at the bottom.<br><br><b>Example:</b><br><code>echo "line1" > file.txt</code> → file contains: <code>line1</code><br><code>echo "line2" >> file.txt</code> → file contains: <code>line1</code> and <code>line2</code>	linux
What does <code>grep -r "password" .</code> do?	Searches <b>recursively</b> through all files in the current directory and subdirectories for the word "password".<br><br><code>-r</code> = recursive (search inside all subfolders too)<br><br>Very useful in security for finding hardcoded credentials, sensitive strings, or IOCs across many files at once.	linux
What does <code>grep -i</code> do?	The <code>-i</code> flag makes grep <b>case insensitive</b>.<br><br><code>grep -i "password" file.txt</code> matches: Password, PASSWORD, passWORD, etc.<br><br>Always use <code>-i</code> when you're not sure how the text is capitalised.	linux
What does <code>grep -v</code> do?	The <code>-v</code> flag <b>inverts</b> the match — shows lines that do <u>NOT</u> contain the search term.<br><br><b>Example:</b> <code>grep -v "Permission denied" output.txt</code><br><br>Useful for filtering out noise from command output.	linux
What is SSH, HTTP and HTTPS? What ports do they use and what is the key difference?	<b>SSH (Secure Shell) — Port 22</b><br>Protocol for remotely controlling another machine via the terminal. All traffic encrypted. Used by sysadmins, developers, and hackers to access remote systems.<br><br><b>HTTP (HyperText Transfer Protocol) — Port 80</b><br>Protocol browsers use to load websites. <u>Unencrypted</u> — anyone on the same network can read the traffic. Never submit passwords over HTTP.<br><br><b>HTTPS (HTTP Secure) — Port 443</b><br>Same as HTTP but with TLS encryption on top. The padlock in the browser = HTTPS. Safe for passwords and sensitive data.<br><br><b>Security note:</b> a login page still using HTTP (port 80) is a vulnerability — always report it.	networking concepts
What is a port? What is the difference between open, closed and filtered?	A <b>port</b> is a numbered endpoint on a server — like apartment numbers in a building. The IP address = the building, the port = the specific apartment.<br><br>Different services listen on different ports:<br>• <b>22</b> = SSH · <b>80</b> = HTTP · <b>443</b> = HTTPS · <b>3306</b> = MySQL<br><br><b>Open</b> — something is actively listening, ready to accept connections.<br><b>Closed</b> — nothing is listening, connection refused.<br><b>Filtered</b> — a firewall blocks it before you reach the service.<br><br><b>Why it matters:</b> open ports = potential attack surfaces. Port scanning is the first step in any penetration test.	networking concepts
What is the difference between: Terminal, Shell, Bash, Command Prompt, and Console?	<b>Terminal</b> — the window/application you open to type commands. Just the interface (e.g. GNOME Terminal, iTerm2, Windows Terminal).<br><br><b>Shell</b> — the program running inside the terminal that reads your commands and executes them. The terminal is the box; the shell is the engine.<br><br><b>Bash</b> — one specific shell. Short for "Bourne Again Shell". Default on most Linux systems.<br><br><b>Other shells:</b> zsh (default on Kali/Mac), fish, sh<br><br><b>Command Prompt (cmd.exe)</b> — Windows equivalent of a terminal+shell. Different syntax, less powerful.<br><br><b>Console</b> — old term, basically means terminal. Often used interchangeably.	linux concepts
What is Bash? How is it different from Python? What is it used for in security?	<b>Bash</b> = the default shell/command interpreter in Linux.<br><br>When you type commands in the terminal, bash reads and runs them. A bash script = a file full of those same commands, run automatically.<br><br><b>Different from Python:</b><br>• Not compiled — runs line by line<br>• Built for OS interaction: files, processes, network<br>• Every terminal command works inside a script<br><br><b>Used in security for:</b> automating scans · parsing log files · quick exploit scripts · setting up environments	linux
What are the key elements of a bash script? (4 questions in 1)	<b>1. Shebang</b> — first line of every script:<br><code>#!/bin/bash</code> — tells the system to use bash<br><br><b>2. Variables</b> — store values:<br><code>TARGET=$1</code> — $1 = first argument the user types<br><code>NAME="kali"</code> — hardcoded value<br><br><b>3. Arrays</b> — store lists:<br><code>PORTS=(22 80 443)</code><br><code>${PORTS[0]}</code> = 22, <code>${PORTS[1]}</code> = 80<br><br><b>4. Comments</b> — ignored by the script:<br><code># this is a comment</code>	linux
How does a <code>for</code> loop work in bash? What does <code>$?</code> mean?	<b>For loop:</b><br><code>for i in 0 1 2; do</code><br><code>  echo ${PORTS[$i]}</code><br><code>done</code><br><br>Runs the body 3 times — once for each value (0, 1, 2).<br><br><b>$? — exit code</b> of the last command:<br>• <code>0</code> = success<br>• anything else = failure<br><br>Used in if statements: <code>if [ $? -eq 0 ]; then</code>	linux
What is the <code>/dev/tcp</code> trick in Linux?	Linux lets you test network connections by writing to a special file path:<br><code>(echo >/dev/tcp/hostname/port) 2>/dev/null</code><br><br>• If the port is <b>open</b> → command succeeds, exit code = 0<br>• If the port is <b>closed</b> → command fails, exit code = 1<br><br>This is how you check if a port is open without installing any extra tools. Used in the port-checker.sh script.	linux tools
